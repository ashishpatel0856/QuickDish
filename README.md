🏠 Online Food Ordering System – Spring Boot
 - **A production-ready Online Food Ordering Backend built using Spring Boot, designed with Clean Architecture, RESTful API principles, and industry-standard security practices.**
   This backend provides core functionalities including authentication, OTP verification, restaurant & menu management, order processing, role-based access control, and payment integration.**

🔐 Authentication & Authorization
 - **User Signup & Login with Role based**
 - **JWT-based Authentication **
- **Secure Password Encryption using BCrypt**
- **reCaptcha verfications**
- **SMTP-based Email OTP Verification**

👥 Role-Based Access Control (RBAC)
- **ADMIN,RESTAURANT,CUSTOMER,Role-specific API authorization using Spring Security**

🍽️ Restaurant & Menu Management
- **Create, update, and delete restaurants**
- **Add, update, and remove menu items**
-- **Manage food availability**
- **Restaurant owners can manage multiple menus**

🔍 Search & Browse
 - **Search restaurants by location**
 - **Search food items by name**
 - **Filter food items by price range**

🛒 Order Management System
- **Place food orders**
- **Availability checks before order placement**
- **Order lifecycle**

PLACED
- **CONFIRMED,PREPARING,DELIVERED,CANCELLED**

💳 Payment Gateway Integration (Stripe)
- **Secure payment processing**
- **Order confirmation after successful payment**
- **Payment status tracking**

📧 Email & OTP Verification
- **OTP generation for user verification**
- **Email-based OTP delivery using SMTP**
- **OTP validation during signup and sensitive operations**

🧱 Technology Stack (Backend)
- **Java 21**
- **Spring Boot**
- **Spring Security**
- **Spring Data JPA (Hibernate)**
- **PostgreSQL**
- **H2 Database (for testing)**
- **Validation**
- **JWT (JSON Web Token)**
- **BCrypt Password Encoder**
- **Actuator**
- **React with vite**
- **tailwind css and react library**

🛠️ Tools & Libraries
- **Maven**
- **Lombok**
- **ModelMapper**
- **Swagger / OpenAPI**
- **Docker**

⚙️ Prerequisites
- **Java 21**
- **Maven 3.8**
- **PostgreSQL**
- **Basic knowledge of Spring Boot and REST APIs**

✅ Project Highlights
- **Clean Architecture**
- **RESTful API Design**
- **Secure and Scalable Backend**
- **OTP-based Email Verification**
- **Production-Ready Codebase**
